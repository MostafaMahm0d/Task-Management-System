# EPIC 6 — Comments & Collaboration

## 🎯 Goal

Enable team communication inside tasks.

## Stories

- Users can comment on tasks
- Users can mention other users
- Users can upload attachments

## Tasks

- Comment model (threaded)
- Mention parser (@user)
- File upload system (S3-ready)
- Filament comment UI

## Acceptance Criteria

- Mentions trigger notifications (future epic)
- Comments are threaded and scoped
