# EPIC 4 — Task Management Engine

## 🎯 Goal

Core ClickUp-like task system.

## Stories

- Users can create tasks
- Tasks can be assigned to users
- Tasks can be filtered and searched
- Tasks support dependencies

## Fields

- title
- description
- status
- priority
- assignee
- reporter
- due_date
- estimated_hours
- labels

## Tasks

- Task CRUD API
- Filament Task Resource
- Task filters (status, priority, assignee)
- Task assignment system
- Task dependency model

## Acceptance Criteria

- Tasks fully tenant-scoped
- Assignment triggers notifications (future epic)
