# EPIC 3 — Project Management System

## 🎯 Goal

Core project structure for SaaS.

## Stories

- Users can create projects
- Users can assign members to projects
- Users can view project dashboards

## Tasks

- Create Project model
- ProjectMember pivot table
- Filament Project Resource
- Project policies
- Project dashboard widgets

## Acceptance Criteria

- Projects are tenant-scoped
- Only project members can access data
- Project roles enforced
